Privacy Policy

This application uses YouTube API Services to automate content uploading and playlist organization.

1. Data Collection & YouTube API Usage

Our internal Content Management System accesses the YouTube API to upload video content, update video thumbnails, and manage playlists. We do not collect, store, or share any personal user data or channel data with third parties.

2. Google Privacy Policy

By using this service, users are also bound by the Google Privacy Policy.

3. Data Deletion & Revocation

This tool acts strictly as a local pipeline. No external personal data is retained. Users can revoke this application's access to their YouTube data at any time via the Google Security Settings page.
